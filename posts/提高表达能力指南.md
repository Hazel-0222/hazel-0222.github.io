## 一、先诊断

### 1.1 自测

- [ ] 别人经常让你"再说一遍"？
- [ ] 说话时发现对方眼神飘走？
- [ ] 汇报了 5 分钟，老板还问"所以呢？"
- [ ] 想好了要说，站起来脑子一片空白？
- [ ] "然后"、"那个"、"就是说"——你的口头禅是哪几个？
- [ ] 说完一段话，自己都觉得逻辑乱？

> 3 条以上中招 → 这篇指南就是为你写的。

### 1.2 四种类型，对症下药

| 类型 | 表现 | 核心问题 | 重点看 |
|------|------|----------|--------|
| 🌀 **浆糊型** | 说一堆，别人不知道重点 | 逻辑混乱 | 思维篇 |
| 🐢 **闷罐型** | 脑子有货，嘴跟不上 | 语感不够 | 表达篇 + 训练篇 |
| 🐿️ **机关枪型** | 语速飞快，信息轰炸 | 节奏失控 | 表达篇 |
| 😰 **紧张型** | 平时正常，正式场合就崩 | 心理障碍 | 训练篇·临场 |

## 二、思维篇 —— 想清楚

> 表达的本质是思维。先想清楚，再说清楚。

### 2.1 金字塔原理

**结论先行，以上统下，归类分组，逻辑递进。**

- **自上而下**：先说结论，再用论据支撑
- **MECE 原则**：相互独立、完全穷尽（不重不漏）

> ❌ "最近登录慢，我们查了服务器，CPU 有点高，数据库查询也有问题，CDN 缓存也过期了..."
>
> ✅ "登录慢，三个原因：**第一**，服务器 CPU 负载过高；**第二**，数据库查询未优化；**第三**，CDN 缓存失效。下面逐一展开。"

### 2.2 四个框架，覆盖所有场景

#### PREP —— 表达观点（最万能）

```
Point    → 观点：我建议推迟上线
Reason   → 理由：测试覆盖率不到 60%
Example  → 案例：上次类似情况上线出了 3 个 P0 故障
Point    → 重申：建议再测一周，8 月 9 号上
```

#### SCQA —— 说服他人

```
Situation    → 现状：我们一直手动打包
Complication → 痛点：上周五误操作，线上挂了 2 小时
Question     → 问题：怎么避免？
Answer       → 答案：引入 CI/CD 自动部署
```

#### STAR —— 讲故事

```
Situation → 背景：去年 Q3，大客户 A 要流失
Task      → 任务：一周内挽回
Action     → 行动：亲自拜访 + 定制方案 + 承诺 SLA
Result    → 结果：续约，追加 30% 预算
```

#### 5W1H —— 把事情说全

```
What → 什么事？      登录页加载慢
Why  → 为什么重要？  影响 30% 用户转化
Who  → 谁负责？      前端 + 后端
When → 什么时候？    本周五出方案
Where→ 影响范围？     PC + H5
How  → 怎么做？      CDN 优化 + 接口合并 + 懒加载
```

### 2.3 三句话法则

任何观点，用三句话讲清：

1. **是什么**（定义）
2. **为什么**（价值）
3. **怎么做**（行动）

> "代码审查就是提交前让同事看一遍。能减少 60% 线上 bug，帮新人快速熟悉代码。从明天起，每个 PR 至少一人 approve 才能合并。"

### 2.4 电梯演讲 —— 30 秒说清一件事

```
我帮 [谁] 解决 [什么问题]，
方法是 [怎么做]，
和 [现有方案] 不一样的是，我们 [核心差异]。
```

## 三、表达篇 —— 说出来

### 3.1 声音三要素

| 要素 | 问题 | 怎么改 |
|------|------|--------|
| **音量** | 太小没底气，太大咄咄逼人 | 以最远的人能听清为准；紧张时下意识提高半格 |
| **语速** | 太快像背书，太慢让人走神 | 正常 180-220 字/分钟，关键处**刻意放慢** |
| **语调** | 全程一个调 = 催眠 | 重要词加重，疑问上扬，陈述下沉，结尾别飘 |

### 3.2 消除口头禅

**常见赘词：** "然后"、"那个"、"就是说"、"嗯"、"反正"、"就是"

**三步戒除：**
1. **发现**：录音回听，数每个口头禅出现几次
2. **阻断**：每次想吐口头禅时，**刻意停顿 1 秒**
3. **替代**：用"第一/第二/第三"替代"然后…然后…"

> 停顿不会让人觉得你卡壳，反而让人觉得你在思考。奥巴马演讲平均停顿 2-3 秒。

### 3.3 让你的声音有"重量"

| 技巧 | 做法 | 效果 |
|------|------|------|
| **句尾下沉** | 最后一字音调往下压 | 更笃定、更可信 |
| **关键词重读** | 每句挑 1-2 个词加重 | 听众能抓住重点 |
| **留白** | 重要的话说完，停 2 秒 | 给对方消化时间 |
| **压低半个音** | 紧张时声音变尖，刻意压低 | 声音更沉稳 |

### 3.4 每日声音唤醒（5 分钟）

```
1. 腹式呼吸 30 秒
   手放肚子上，吸气鼓肚子（不耸肩），呼气收肚子，5 次

2. 哼鸣开嗓 30 秒
   闭嘴用"嗯——"从低到高再回低，感受鼻腔震动

3. 绕口令 2 分钟
   选 2 条，先慢后快，每条 3 遍
   → 详见 [绕口令训练集](03-声音-绕口令训练集.md)

4. 朗读 2 分钟
   一段文字用三种情绪各读一遍：平淡 → 激昂 → 温柔
```

### 3.5 肢体语言

| 要素 | ❌ 别这样 | ✅ 这样 |
|------|----------|--------|
| **站姿** | 驼背、晃来晃去、重心一条腿 | 双脚与肩同宽，站稳，重心均匀 |
| **手势** | 插口袋、交叉手臂、玩笔 | 手掌打开，配合说话节奏，比划数字举起来 |
| **眼神** | 盯天花板、盯地板、只盯一个人 | 看眉心/鼻梁，每 3-5 秒换一个人 |
| **表情** | 全程面无表情 | 开场微笑，严肃内容收笑，幽默时自己先笑一点 |

**视频通话：** 摄像头与眼睛平齐，看摄像头而非屏幕，光从前方来。

> 7-38-55 法则：在情绪沟通中，内容 7%，语音语调 38%，肢体语言 55%。

## 四、实战篇 —— 场景模板

### 4.1 即兴表达技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **先报数字** | 开口先说"我有三点看法" | 听众立刻知道结构 |
| **停顿代替赘词** | 想说"嗯"时闭嘴 1 秒 | — |
| **放慢一半** | 你以为的正常语速，大概率偏快 | 暗示自己："在对小孩说话" |
| **用比喻** | 抽象概念 + 生活化比喻 | "这个系统就像水管，人多了就堵" |
| **先接住再展开** | 被提问时先重复问题 | "你问的是 XX 对吧？"（争取 3 秒） |
| **不说绝对词** | 少用"永远""绝对""一定" | "目前来看"比"永远"更可信 |

### 4.2 会议发言

**抛出观点：**
> "关于这个问题，我的看法是___。理由有三：第一___；第二___；第三___。所以我的建议是___。"

**提出反对（不伤和气）：**
> "我理解你的思路，从___角度看确实有道理。不过我想补充一个角度___。也许我们可以___。"

**即兴总结：**
> "今天讨论的核心是___，我们达成了___共识，下一步是___。"

**被突然点名：**
> "这个问题很有意思，我从两个方面来回答。首先___；其次___。"

### 4.3 进度汇报

**例行汇报：**
> "本周完成了___，正在做___，预计___完成。目前的风险是___，我计划的应对是___。需要你帮忙的是___。"

**汇报坏消息：**
> "有一个情况需要同步——___可能延期。原因是___。我们已经在做___，预计影响___。需要你帮忙的是___。下次怎么避免：___。"

**PM 实战 —— 向制作人汇报里程碑：**
> "Alpha 版本整体进度 70%。**完成的**：核心战斗系统已跑通，3 个角色动作已接入。**延期的**：UI 系统比预期晚 3 天，原因是美术资源上周才交付。**应对**：程序先切 UI 框架，资源到了直接填。**风险**：如果这周五资源还不到，可能影响下周的体验测试。**建议**：美术这边加一个人支援 3 天，你看可以吗？"

### 4.4 跨部门沟通

**跟策划沟通需求变更：**
> "我理解你希望实现___效果，这个确实能让体验更好。不过从技术角度看，实现这个需要___，大概要多花___天。我们有两个选择：**A**——简化方案，用___替代，效果接近但省时间；**B**——做完整版，但___功能可能要往后挪。你觉得哪个更合适？"

**跟程序解释优先级：**
> "我知道你想把___做到完美，但下周的 milestone 需要的是可演示版本。我的建议是：先把核心流程跑通，___的优化我们放到下一个 sprint。不是不做，是分步做。"

**跟美术沟通技术限制：**
> "这个效果确实很酷。但引擎这边有个限制——___。我们可以这样：___部分保持不变，___部分做调整，整体效果基本不受影响。要不我让程序出一个 demo 你先看看？"

### 4.5 一对一沟通

**了解情况：**
> "关于___，我想听听你的想法。你目前怎么看？有什么困难吗？"

**给反馈：**
> "你在___方面做得很好，尤其是___。有一个地方可以更好——___。我的建议是___，你觉得呢？"

**拒绝别人：**
> "我很想帮忙，但___（客观原因）。不过我可以___（替代方案）。你看这样行吗？"

### 4.6 让你的话有画面感

| 方法 | ❌ 差 | ✅ 好 |
|------|-------|------|
| **用数字** | "加载很慢" | "从 3 秒变成了 8 秒" |
| **用对比** | "优化后更快了" | "之前跑 3 小时，现在 8 分钟" |
| **用场景** | "体验不好" | "测试点了按钮，等了 5 秒，然后把手机放下了" |
| **用类比** | "架构很复杂" | "这就像在建一个商场的同时还要营业" |

### 4.7 讲故事公式

```
1. 场景：时间、地点、人物（"上个月，策划提了一个需求..."）
2. 冲突：遇到了什么困难（"程序说做不了，工期不够"）
3. 转折：做了什么（"我没急着协调，先让两边各说清楚真正要什么"）
4. 结果：发生了什么（"发现核心诉求其实用现有方案就能满足 80%"）
5. 感悟：提炼的道理（"很多时候不是做不了，是没翻译对"）
```

## 五、训练篇 —— 怎么练

### 5.1 核心练习方法

#### 🎙️ 录音复盘（最有效）

1. 每天选一个话题，手机录 **2 分钟**即兴表达
2. 回听，记下：口头禅次数、逻辑跳点、语速问题
3. 重新录一遍，对比改进
4. 每周回听第一天录音，感受进步

#### 📖 费曼学习法

> 如果你不能简单地解释它，你就没有真正理解它。

1. 选一个概念，假装讲给完全不懂的人
2. 卡住的地方就是你的盲区
3. 回去学明白，再用更简单的话复述
4. 反复直到能用"人话"讲清楚

#### 🗣️ 一分钟复述

看完一篇文章/视频 → 立刻用 **1 分钟**口头复述 → 进阶：**30 秒**再来一遍

#### 🎭 影子跟读

选一段演讲，跟在演讲者后面同步复述，模仿语调、停顿、情绪。

> 📎 跟读素材：[04-跟读-影子跟读训练素材.md](04-跟读-影子跟读训练素材.md)

### 5.2 素材积累

表达能力的天花板，是你的**输入量**。

**日常积累：**
- 每天精读一篇好文章，拆解结构
- 遇到精彩的比喻，立刻记到备忘录
- 观察身边会说话的人，分析他的技巧
- 通勤时听播客，学聊天节奏

**建立素材库：**

```
📦 素材库
├── 📖 好故事    → 亲身经历、听来的故事、案例
├── 💡 好观点    → 让你"原来如此"的洞见
└── 🎯 好比喻    → 精彩的类比和形象化表达
```

### 5.3 临场调节

> 紧张不是缺陷，是身体在为你准备能量。高手的区别不是紧不紧张，而是紧张时还能不能正常表达。

**上台前 10 分钟：**
- 10 分前：3 轮 4-7-8 呼吸法（吸 4 秒 → 屏 7 秒 → 呼 8 秒）
- 5 分前：喝一小口温水，活动肩膀
- 3 分前：默念开场前三句，练到肌肉记忆
- 1 分前：站直，双脚踩实，微笑

**脑子空白时：**
1. 重复问题："你问的是___，对吗？"（争取 3 秒）
2. 喝口水，微笑（再争取 5 秒）
3. 诚实说："这个问题我需要想一下"（比瞎编好一万倍）
4. 从最简单的说起，边想边展开

**长期克服紧张：**
- 脱敏训练：每周主动在小场合发言一次
- 准备过度：准备 150% 的内容，只讲 100%
- 回看录像：你会发现"没想象中那么糟"
- 规律运动：降低基础焦虑水平

### 5.4 八周训练计划

| 阶段 | 周次 | 每日任务 | 时长 |
|------|------|----------|------|
| **基础** | 1 | 录音 2 分钟 + 回听复盘 | 15 分钟 |
| | 2 | 录音 + 绕口令 + 朗读 | 20 分钟 |
| **进阶** | 3 | 影子跟读入门（火星爷爷/蒋勋） | 20 分钟 |
| | 4 | 影子跟读 + 一分钟复述 | 25 分钟 |
| **实战** | 5 | 工作中刻意用 PREP 框架发言 ≥1 次 | 25 分钟 |
| | 6 | 刻意练习一个场景模板（汇报/跨部门） | 25 分钟 |
| **巩固** | 7 | 完整脱稿复述一篇 TED 演讲 | 30 分钟 |
| | 8 | 录 5 分钟主题演讲，对比第 1 周 | 30 分钟 |

### 5.5 每日录音话题

- 今天最让你兴奋的一件事
- 最近学到的一个新知识
- 用 2 分钟介绍你的项目
- 评价一本你最近看的书/电影
- 今天遇到的一个沟通难题，重来会怎么说
- 用 PREP 框架分析一个热点
- 用 STAR 框架讲一个最近的成就

## 核心要点

1. **表达的本质是思维** —— 先想清楚，再说清楚
2. **结论先行** —— 永远先告诉对方你的核心观点
3. **三句话讲清一件事** —— 是什么、为什么、怎么做
4. **录音复盘是最快的进步** —— 听自己说话很痛苦，但最有效
5. **停顿比赘词好一万倍** —— 闭嘴 1 秒，比"然后…然后…"强
6. **影子跟读练的是"语感"** —— 像学唱歌一样学说话
7. **阅读是输入的源头** —— 肚子里没货，说什么都空洞
8. **每次开口都是练习** —— 刻意练习，而非随便说说
9. **紧张是身体在为你准备能量** —— 不是敌人
10. **好表达 = 让对方少花力气理解** —— 把复杂留给自己，把简单留给别人
