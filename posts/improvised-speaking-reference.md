# 即兴回答训练参考库

> 配套 Anki 卡型（表达框架 / 关键词 / 逻辑连接词 / 讲稿）使用的词汇与框架参考。
> 核心用法：**看到信号 → 秒配框架 → 列关键词 → 用连接词串联 → 说讲稿**。

---

## 一、表达框架（思考的骨架）

**定义**：接收到问题的瞬间，用来"框定"回答方向的框架模型。
**原则**：**只记 5 个根框架 + 2 个专项**，其余全部是它们的换皮。根框架决定"骨架形状"，子项只在需要时换外壳，避免每道题听起来一样。
**用法**：表达框架字段只存一行 —— `信号 → 根框架（子项可选）`，例如 `怎么办？→ 时间轴 · 分步（诊断-引导-固化）`。

### 1.1 五大根框架（先练熟这 5 个，就够覆盖八成的题）

| 根框架 | 一句话骨架 | 触发信号 | 常用子项（换皮说法） |
|---|---|---|---|
| **① 时间** | 事情按先后推进，说"怎么一步步到结果" | 怎么办 / 处理 XX / 规划 / 组织活动 / 突发状况 | 1. 分三步走<br>2. 前-中-后<br>3. 过去-现在-未来<br>4. 方案-执行-复盘<br>5. 稳-查-处-复（突发急版） |
| **② 维度** | 换个对象/视角再说一遍，从里往外展开 | 你怎么看 XX / 谈理解 / 分析原因 | 1. 自己-他人-组织<br>2. 微观-中观-宏观<br>3. 内因-外因<br>4. 基层-单位-全局 |
| **③ 正反** | 先说是，再说不是，最后说怎么弥补 | 利弊 / 争议 / 两难 / 对方质疑 | 1. 正-反-合<br>2. 利-弊-利<br>3. 认可-不足-建议 |
| **④ 叙事（STAR）** | 讲一件具体的事，让人"看见"你 | 请举例 / 讲经历 / 优缺点 | 1. STAR(-L)<br>2. 挑战-应对-收获<br>3. 特点-例证-匹配（优缺点版） |
| **⑤ 万能三问** | 是什么-为什么-怎么办，兜住一切 | 想不出更合适的，就用它 | 1. 定性-定策-定责（默认）<br>2. 现象-本质-对策<br>3. 判断-依据-建议<br>4. 理解-分析-落实<br>5. 实战 · 事-人-环境（例：如何分配任务） |

核心就 **5 个触发词**：`怎么办 → 时间轴`，`怎么看 → 空间轴`，`有争议 → 辩证`，`请举例 → 叙事`，`没把握 → 三问`。

### 1.2 专项（遇到对应题型才启用，不占用日常反应）

| 专项 | 骨架 | 触发信号 | 一句话示例 |
|---|---|---|---|
| **情理法** | 动之以情 → 晓之以理 → 明之以规 | 说服 / 协调矛盾 / 拒绝 | 同事不支持你方案 → 共情-说理-按制度办 |
| **字面-引申-结合** | 本义 → 深层含义 → 落到工作/自身 | 解释一个词 / 一句话 | 什么叫靠谱 → 字面-闭环-我怎么做 |

### 1.3 快速反应训练顺序

1. **先只记 5 个触发词**（怎么办/怎么看/争议/举例/兜底），对着题干脱口而出根框架——这决定你能不能 2 秒出框架。
2. 根框架稳定后，每根背 **1-2 个子项**换皮即可，多背会乱。
3. 突发状况的"稳-查-处-复"不用单独背：它就是时间轴的急版，先稳场再处理。
4. 两个专项独立成卡，遇到对应题型再调用。

## 二、逻辑连接词（表达的胶水）

**定义**：把关键词和句子串联成流畅语流的过渡词。
**用法**：按功能分组记忆，说到对应位置时把它"接"上去，重点练熟每一组的**首选 1-2 个**，不必全背。

### 2.1 逻辑连接词总表

| 分类 | 什么时候用 | 首选 | 备选 |
|---|---|---|---|
| 框架连接 | 说到第几点 | 首先 / 其次 / 最后 | 一来·二来 / 第一…第二…第三… / 一方面…另一方面… |
| 递进 | 往深了说 | 更准确地说 | 在此基础上 / 更进一步 / 尤其重要的是 / 甚至可以 / 不光是…更是… |
| 转折 | 换一边 / 纠偏 | 不过 | 当然 / 与此同时 / 反过来看 / 但需要注意的是 / 这并不意味着 |
| 因果 | 解释为什么 | 因此 | 这就导致了 / 这意味着 / 之所以…是因为… / 说到底 |
| 举例 | 落地到具体事例 | 举个例子 | 比如 / 以…为例 / 具体来说 |
| 补充 | 搭便车多讲一点 | 另外 | 除此以外 / 值得一提的是 / 顺带一提 |
| 让步 | 先认可再展开 | 当然，我们也不是完全不近人情 | 不可否认 / 从某个角度讲确实 / 他的出发点可以理解 |
| 收尾 | 总结 / 升华 | 总而言之 | 归根结底 / 说白了 / 所以我的结论是 / 如果用一句话总结 |

### 2.2 使用要点

- **每类只熟 1-2 个**，练到脱口而出；贪多反而卡壳。
- 递进 + 转折连着用几乎能扛住所有长回答："首先（框架）…更准确地说（递进）…不过（转折）…因此（收束）"。
- 逻辑连接词是**口语胶水**，不是书面连接词，别用"综上所述、总而言之"开头，会像背稿。

### 2.3 按框架配连接词（槽位对照）

把第二节的词"焊死"到各根框架的槽位上——说出第几个槽位，对应的词自动蹦出来。**没有新词，全是上面已有词的重新组合。**

| 框架 | 槽位 | 首选连接词 | 备注 |
|---|---|---|---|
| **① 时间** | 第一步 | 首先 / 一开始 | |
| | 第二步 | 接下来 / 然后 | |
| | 第三步 | 最后 / 到最后一步 | |
| | 收尾 | 这样一来… / 因此… | |
| **② 维度** | 第一层（自己） | 从个人层面看… | 从里面先讲 |
| | 换层（他人） | 其次，再往上看… | |
| | 最高层（组织） | 放到更大范围看 / 综合来看… | 爬到顶收住 |
| **③ 正反** | 总起 | 从利弊两方面看… / 这件事有利有弊… | 先宣告"讲两面" |
| | 正向 | 当然，我们也不是完全不近人情 / 不可否认 / 从积极的一面看 | |
| | 反向 | 不过 / 但换个角度 / 与此同时也要看到 | |
| | 收束 | 权衡利弊下来… / 综合来看 / 所以 | 收束可呼应总起 |
| **④ 叙事** | 背景 | 当时 / 起因是… | |
| | 行动 | 于是 / 所以我… / 具体我是这么做的 | |
| | 结果 | 最终 / 结果… | |
| | 反思（可选） | 回过头看 / 这件事让我意识到… | |
| **⑤ 三问** | 是什么 | 在我看来… | 亮明判断 |
| | 为什么 | 之所以…是因为… / 关键原因在于 | |
| | 怎么办 | 所以，落实到做法上… / 具体可以… | |

**最值得专练的组合**：③ 正反 —— 总起"从利弊两方面看" → 正向"当然，我们也不是完全不近人情" → 反向"不过" → 收束"权衡利弊下来"，首尾两个"利弊"呼应，结构感最强。

## 三、关键词（思考的路标）

**定义**：在选定的表达框架内，决定填充进去的 3-5 个核心内容点。
**用法**：关键词不是"好词"综合表，而是**按题型各配一组骨架词**，看到题目先选 3-5 个，再串成句。

### 3.1 处理 / 解决问题类（怎么办）

| 分组 | 词汇 |
|---|---|
| 工作动词 · 诊断准备 | 诊断 / 盘点 / 梳理 / 界定 / 分级 / 排序 |
| 工作动词 · 拆解协作 | 制定 / 拆解 / 分工 / 对齐 / 沟通 / 协调 |
| 工作动词 · 落地收尾 | 执行 / 落地 / 跟踪 / 反馈 / 复盘 / 固化 |
| 高频名词 | 方案 / 流程 / 机制 / 规范 / 预案 / 台账 / 闭环 / 抓手 / 接口 / 权限 / 边界 / 节点 |
| 示例搭配 | `诊断-拆解-对齐-闭环`（时间 · 分步的四词版） |

### 3.2 分析 / 表态类（怎么看）

| 分组 | 词汇 |
|---|---|
| 表态核心 | 本质 / 导向 / 价值 / 意义 / 危害 |
| 成因与权衡 | 内因 / 外因 / 诉求 / 矛盾 / 权衡 / 平衡 |
| 标准与底线 | 标杆 / 底线 / 红线 / 标准 / 生态 |
| 范围与视角 | 长期 / 短期 / 局部 / 全局 |
| 示例搭配 | `本质-诉求-平衡`（维度框架四词版） |

### 3.3 观点 / 政策理解类

| 分组 | 词汇 |
|---|---|
| 目的与手段 | 初衷 / 目的 / 手段 / 效果 |
| 主体与边界 | 对象 / 主体 / 责任 / 边界 |
| 落地与监督 | 落地 / 配套 / 细化 / 监督 / 纠偏 |
| 受众与普遍性 | 群众 / 基层 / 实际 / 普遍性 |

### 3.4 突发事件 / 应急类

| 分组 | 词汇 |
|---|---|
| 应急动作 | 稳现场 / 控舆情 / 报上级 / 组专班 |
| 核实与分级 | 查明 / 核实 / 分类 / 分级 / 优先级 |
| 方案与补救 | 临时方案 / 预备方案 / 补救 / 问责 / 追责 |
| 事后预防 | 建制度 / 堵漏洞 / 防复发 |

### 3.5 自我展示类（经历 / 优缺点 / 为什么是你）

| 分组 | 词汇 |
|---|---|
| 能力词 | 自驱力 / 抗压 / 复盘习惯 / 结果导向 / 闭环思维<br>时间管理 / 多任务 / 跨部门协作 / 快速学习 / 数据敏感 |
| 经历描述词 | 资源紧张 / 信息不对称 / 时间紧 / 责任大<br>立目标 / 排优先级 / 主动补位 / 超预期交付 |
| 示例搭配 | `资源紧张-主动补位-超预期交付`（叙事（STAR）的 A-R 两词） |

### 3.6 使用要点

- **先定框架再挑关键词**：框架决定"要几点、几点之间什么关系"，关键词决定"每点说什么"。
- 一组 3-5 个即可；选词时问自己"这 3 个词能不能串成一句完整的话"，串不起来就换。
- 逐题积累自己的关键词组，熟到"看到题干词 → 该题的专属关键词组"直接冒出来。

## 四、一张卡的完整组装示例

以"如何处理部门之间的冲突？"为例：

| 字段 | 内容 |
|---|---|
| 表达框架 | 怎么办 → 时间轴 · 分步（诊断-引导-固化） |
| 关键词 | 诊断（分头沟通/核实诉求）· 引导（对齐目标/求同存异）· 固化（流程/机制防复发） |
| 逻辑连接词 | 首先… 更准确地说… 不过… 因此… |
| 讲稿 | 首先我会先诊断，分别了解双方的真实诉求……更准确地说，是分清原则性分歧和操作性分歧……不过，推动对齐不能靠压服，要靠共同目标……因此，最后把共识固化成流程，避免下次再犯。 |

以"如何合理分配任务"（⑤ 万能三问 · 实战子项）为例：

| 字段 | 内容 |
|---|---|
| 表达框架 | 怎么办 → 万能三问 · 实战（事-人-环境） |
| 关键词 | 任务：优先级 · 排期<br>负责人：能力 · 经验 · 出勤<br>外部：监修 · 外包资源 |
| 逻辑连接词 | 首先从任务本身看… → 其次看负责人… → 另外还要看外部… → 综合下来… |
| 讲稿 | 分配任务我没有一刀切的办法，会从三个方面拆：任务、人、外部条件。<br>首先看任务本身——优先级高不高、排期紧不紧，决定能不能并行、要不要先派人顶上。<br>其次看负责人——能力够不够，过往有没有做过类似的事、多久能交付，近期有没有请假安排，这些直接决定我敢不敢把这摊活交出去。<br>另外还要看外部因素——要不要过监修，需不需要拉外包资源补位。<br>综合下来，把合适的任务排给合适的人，再留出缓冲应对突发变化。 |

## 五、复习建议

1. **框架卡**（练秒反应）：正面出信号、背面出根框架。**先只练 5 个触发词**（怎么办/怎么看/争议/举例/兜底），熟练后加 2 个专项，目标"看到题干 2 秒出框架"。
2. **关键词卡**：框架 + 题型固定在正面，背面出 3-5 个关键词组。
3. **连接词卡**：正面出功能（递进/转折），背面出首选词，连成短语整块练。
4. **讲稿卡**：正面出"框架+关键词"，背面出完整回答，重点练"能说出口的人话"，不是背逐字稿。
